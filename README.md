# Tastes of Africa

A website dedicated to showcasing African foods by country and region, along with recipes and preparation guides.

---

## Project Structure

```
African_taste/
├── index.html
├── recipes.html
├── regions.html
├── about.html
├── contact.html
├── recipe-jollof.html
├── recipe-injera.html
├── recipe-tagine.html
├── css/
│   └── styles.css
├── js/
│   └── script.js
├── images/
│   └── (all food and hero images)
└── README.md
```

## Technologies Used

- **HTML5** — For Structuring the page.
- **CSS** — For styling and making layout.
- **JavaScript** — recipe filter, favourites, and contact form validation
- **Google Fonts** — For fonts especially the titles.
- **Google Maps Embed API** — maps



## Pages Overview

| `index.html` | Home page with featured dishes, explore by region, and latest food trends |
| `recipes.html` | Full recipe listing with filter by region |
| `recipe-jollof.html` | Jollof Rice recipe detail with ingredients, instructions, nutrition facts, video and map |
| `recipe-injera.html` | Injera recipe detail with ingredients, instructions, video and map |
| `recipe-tagine.html` | Moroccan Tagine recipe detail with ingredients, instructions, video and map |
| `regions.html` | Explores West and East African culinary regions with dishes and videos |
| `about.html` | Mission statement, history of African food culture, and partner restaurant map |
| `contact.html` | Contact form for messages and recipe submissions |

---

## Features

- Embedded YouTube videos for African food culture and individual recipes
- Google Maps embeds showing countries of origin for each dish
- Recipe filter by region (West, East, North Africa)
- Save to favourites button on each recipe card
- Contact form with country selector and message validation
- Responsive navigation with active page highlighting
- Hero section with background image and embedded intro video
- Latest Food Trends articles section
